Repository for Machine Problem #2 in compliance with my ELECTIVE 4 course.

## Description

This project features a desktop greeting application built with Python and Tkinter (`hello.py`). The program provides a graphical user interface (GUI) where users can enter their name, click a button (or press Enter), and receive a personalized greeting message.

## Features

- **User-Friendly GUI**: Clean interface built using Tkinter and `ttk` widgets.
- **Interactive Greeting**: Prompts for a user's name and displays `Hello, <name>!` (or `Hello, World!` if left blank).
- **Keyboard Shortcut**: Supports pressing the `Enter` (`Return`) key to submit.

## Getting Started

### Prerequisites

- Python 3.x (Tkinter is included by default with standard Python installations)

### Running the Application

Execute the following command in your terminal:

```bash
python hello.py
```
